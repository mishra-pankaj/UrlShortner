URL Shortener API

A lightweight, high-performance URL shortening service built with Node.js, Express, and MongoDB. This project uses Nano ID to generate unique, URL-friendly identifiers.

🚀 Features

Custom Short Links: Generates a unique, compact string for any long URL.

Redirection: Automatically redirects users to the original long URL via the short code.

Validation: Ensures only valid URLs are processed.

Persistent Storage: Uses MongoDB to store mappings securely.

🛠️ Tech Stack

Runtime: Node.js

Framework: Express.js

Database: MongoDB (via Mongoose)

ID Generator: Nano ID
